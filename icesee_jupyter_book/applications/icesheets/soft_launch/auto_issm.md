# Auto-config ISSM: review and apply one solver setting

The 194-second silent walkthrough changes the canonical SquareIceShelf
stressbalance iteration cap from 100 to 120, then checks the submitted setting,
native fields and downloaded archive. Use the visible Do-this/Why/Look-for panel;
optional guided mode pauses after each complete recorded confirmation.

## Before you start

Begin with [Icepack Basic](basic_icepack.md) for the first cloud experience.
For this ISSM case, finish [Basic ISSM](basic_issm.md), review your
[BYO AWS connection](byo_aws_setup.md), and configure **your own MATLAB license
plus a live same-owner Connector** as described in [MATLAB setup](matlab_byo_setup.md).
The recorded route is native BYO: charges go to the explicitly connected AWS
account. The [saved internal budgets](pilot_readiness.md) do not activate hosted
execution or fund an AWS balance.

Keep **Cloud → ISSM → SquareIceShelf** selected and reuse the reviewed image,
resources and time ceiling. This case proposes and applies one numerical
setting; planning and applying the configuration do not submit a model job.

## Follow the controls

1. Keep the **canonical SquareIceShelf** example selected, rather than a modified Advanced clone. Select **Auto-config · Beta**.
2. Enter **Set stressbalance max iterations to 120.** The supported key is `stressbalance.maxiter`, labelled **Stressbalance max iterations**. Its UI default is 100 and the supported integer range is 1–1000.
3. Choose **Create plan**. Check that the proposal retains ISSM, SquareIceShelf and your current route, with only the iteration cap set to 120.
4. Choose **Apply to configuration** explicitly. Confirm the proposed setting is applied; a model job has not started.
5. Choose **Review in Advanced**. Inspect the enabled override, `runme.m` target, model/example, image/resources and license readiness.
6. Open **Review & Launch**, inspect the final plan, and choose **Launch cloud run** once. Follow its new submission to completion.
7. Open the completed run's **Workspace → Results**, select **StressbalanceSolution → Vel**, and choose **Render**. Generate the fresh download link, save the ZIP, and inspect its fields and provenance.

Use the ordinary player for continuous viewing, or Start guided walkthrough to
pause after recorded confirmations. The checklist is for you to mark after your
own action; watching the recording does not operate CryoLauncher.

## Model reference and recorded settings

Download the {download}`canonical matched model source <basic-issm-matched-source.zip>`
and <a href="videos/issm-autoconfig-settings-120.json">the recorded 120-cap settings</a>.
No source import is required to follow this built-in-example video. The four-file
ZIP is the canonical reference used by Basic, not a byte-identical copy of every
Auto-config execution wrapper.

The submitted Auto-config `runme.m` adds one before-solve override hook. Removing
that one hook matches canonical `runme.m` exactly; DomainOutline.exp, Front.exp
and Square.par remain canonical. The actual submitted assignment, normalized
