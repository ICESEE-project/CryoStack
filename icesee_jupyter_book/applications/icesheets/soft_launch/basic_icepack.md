# Basic Icepack: from a first check to an ice-shelf solve

Start with **00 Meshes Functions** to check execution and figures. Then run
**02 Synthetic Ice Shelf** for a larger native flow simulation. These are two
different checks; the mesh/functions example does not solve glacier flow.

## Before you start

Complete [Before your first run](../soft_launch.md) (account, approval, AWS
connection). Sign in to [CryoLauncher](https://cryostack.eas.gatech.edu/cryolauncher/) using the
access and funding arrangement confirmed in your invitation. A connected AWS
account is not proof of a project-funded allocation. If the promised allocation
is absent, contact the organizer before running. Do not create a personal AWS
account or enter payment details unless the organizer explicitly requests it.

Run one job at a time and keep the tested container. Icepack does not need a
MATLAB license or a Connector for MATLAB licensing. A short calculation can take
several minutes overall while AWS prepares the container. A displayed 60-minute
time limit is a ceiling; it is not a measured runtime for these examples.

## First run: meshes and figures

1. Select **Cloud**, **Basic**, then **Icepack**.
2. Choose **Tutorial / 00 Meshes Functions**. Confirm that Details names this example.
3. Check **Cloud Environment**. If Account shows **Connected** and Storage,
   Containers and Compute show **Ready**, continue. If resources need preparation, follow the
   organizer's instructions before using **Prepare cloud**.
4. Open **Review & Launch**. Check the model, image, region, resource shape and
   time limit. Resolve a missing cost estimate with the organizer before a pilot run.
5. Click **Launch cloud run** once. Watch the job progress to **Completed**;
   **View log** retrieves the current job's log when it becomes available.
6. Open **View results** and inspect the generated figures. Structured thickness
   and velocity fields are not expected from this mesh/functions example.
7. Click **Download results**, then its download link. Finish the browser's save
   step and open the saved ZIP. A generated link alone is not a completed download.

The recorded check produced seven figures and a nonempty archive. Its container
ran for about 53 seconds, with about 4.6 minutes from submission to stop. Your
startup time can differ.

## Optional larger run: synthetic ice shelf

1. Keep **Cloud / Basic / Icepack**, then choose **Tutorial / 02 Synthetic Ice Shelf**.
2. Leave the scientific parameters at their defaults for this comparison. The
   tutorial performs 200 steps in each of two 400-year phases; it is not a
   one-minute smoke test.
3. Review the new example and resources, then launch once. Allow time for image
   startup as well as solving. Keep the page open to watch the current job.
4. On completion, open **View results**. Select the `icepack` solution and inspect
   **velocity**, **thickness**, **accumulation** and **damage**. Use **Render** after
   changing a field. The reference export has 3,371 nodes and 6,533 triangles.
5. Save the results ZIP. The recorded output contained mesh data, four field
   files, metadata and eight figures. Confirm the archive opens without an error.

The recorded AWS execution took about 7.4 minutes, or 11.3 minutes including
startup. This is an observed sample, not a promised duration. It used the owner's
connected account; an ordinary participant's funded access still needs the
organizer's release confirmation.

![Example exported velocity field from the synthetic shelf](images/basic-icepack-shelf-velocity.png)

Thickness and velocity are exported to a portable CG1 representation. The damage
simulation has a measured negative undershoot (about -0.003602), retained without
clipping. Reproducing that numerical output does not establish physical accuracy.
See [PC versus AWS comparison](comparison.md) for the matching source and reference.

## Next steps

For a smaller flow solve using your own input, follow [uploading a dataset](upload_dataset.md).
For editing and extending scripts, continue with [Advanced Icepack](advanced_icepack.md).

**Recording:** the [recording matrix](recording_matrix.md) uses 02 Synthetic Ice Shelf for the Basic Icepack walkthrough and includes the Basic controls. The earlier shelf execution reference above does not count as a new recording.
Use a clean participant test account and keep account identifiers, license fields,
tokens and private paths outside the recording.
