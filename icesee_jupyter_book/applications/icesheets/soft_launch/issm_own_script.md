# ISSM: bring your own script

This 247-second beginner tutorial imports a three-file MATLAB workflow and its
synthetic JSON input, runs native ISSM, then renders and saves the results.
Start with [Basic ISSM](basic_issm.md) and your reviewed
[BYO AWS connection](byo_aws_setup.md) plus
[MATLAB license/Connector setup](matlab_byo_setup.md). Sign in with an approved
account and keep the existing license/Connector ready. This recording uses the
current native BYO route.

## What this script solves

This is a **10 km × 10 km synthetic floating shelf**. Triangle uses the JSON's
**2,500 m mesh spacing**; the retained mesh has **13 vertices and 16 triangles**,
covering **100,000,000 m²**. The parameter file sets thickness from 500 m at
`y=0` to 300 m at `y=width`, and computes hydrostatic base/surface using the
runtime material densities. The calving-front contour is at `y=width`.
Temperature is **253.15 K**.

Initial vx/vy are **zero**. `SetIceShelfBC` supplies zero finite non-front
velocity constraints for this source, which provides no observed velocity
arrays. The shared JSON's **100 m/year inflow velocity is unused** by this ISSM
workflow. Its `dt_years`, `mesh_nx` and `mesh_ny` are also unused. The file's
`timesteps=1` triggers **one diagnostic SSA Stressbalance solve**, with requested
**np=1**, and **no physical time advance**. It is not a 0.01-year transient run.

The model retains solved `md` for export. Its MATLAB MCOS representation is
opaque to these local readers, so the thickness formula and zero initial/BC
settings are source-confirmed; they are not independently decoded from the
saved model. A topology-based check infers five non-front boundary vertices and
finds solved vx/vy exactly zero there. That observable-field check does not
decode the saved constraint arrays.
