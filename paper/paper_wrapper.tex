\begin{abstract}
CryoStack unifies scientific applications, per-user workspaces and experiment
histories, data catalogs, structured result contracts, and heterogeneous
execution resources for reproducible cryosphere computing. This software paper
describes the implemented architecture, including remote HPC execution through
a connector-mediated relay and an AWS Batch path for one model, and clearly
identifies the integration and production-hardening work that remains.
\end{abstract}
